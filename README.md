## Как читать статусы и формат

**Ожидает актуализации** — исходный файл перенесён без изменения содержимого. Перенос проверен,
но команды, примеры и утверждения ещё требуют технического обновления. Даты актуальности внутри
таких файлов относятся к исходному тексту и не подтверждают новую проверку.

**Пилот актуализирован** — материал переработан по общему шаблону. В паспорте темы отдельно
указаны сверка с документацией, выполненные примеры и сценарии, требующие дополнительного окружения.

Компактная тема остаётся одним файлом. Объёмная тема получает каталог с кратким `README.md`
и подробными страницами по задачам. В актуализированных материалах выделяются базовый, средний
и продвинутый уровни; перенесённые исходники будут приведены к этому формату постепенно.

| Уровень | Что в нём искать |
| --- | --- |
| Базовый | Первые рабочие операции, основные команды и понятия |
| Средний | Типовые рабочие сценарии и сочетание нескольких возможностей |
| Продвинутый | Сложные случаи, конкурентность, оптимизация и эксплуатация |

У больших тем начинай с краткого `README.md`: его быстрый поиск ведёт к подробным страницам.
Требования и ограничения примера указываются рядом с ним на любом уровне.

У каждой темы одно основное место: SQL и особенности СУБД — в `databases/`, библиотеки доступа
к БД из Python — в `python/databases/`, Git и GitHub — в `tools/`. Смежные темы связаны ссылками.
