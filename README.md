Русскоязычные шпаргалки и практические руководства: Python и Go, базы данных, Linux,
инструменты разработки, архитектурные принципы и паттерны.

«откат / undo», «резервная копия / backup», «повтор запроса / retry».
Для обзора технологий выбери тему в таблице ниже или каталог раздела.

- [Go](go/README.md) — язык, стандартная библиотека, конкурентность и тестирование.
- [Базы данных](databases/README.md) — SQL, PostgreSQL, SQLite и Redis.
- [Операционные системы](systems/README.md) — Linux, оболочка и эксплуатационные команды.
- [Архитектура](architecture/README.md) — выбор по задаче, карточки SOLID, схемы и структуры пакетов.

## Как читать статусы и формат

**Актуализировано** — существующая тема переработана по общему шаблону.
**Добавлено** — новая тема оформлена по тому же правилу. В паспорте каждой страницы отдельно
указаны источники, даты, выполненные примеры и сценарии, требующие дополнительного окружения.

Компактная тема остаётся одним файлом. Объёмная тема получает каталог с кратким `README.md`
и подробными страницами по задачам. В кратких справочниках выделяются базовый, средний
и продвинутый уровни. Подробные страницы указывают свой уровень и предпосылки.

| Уровень | Что в нём искать |
| --- | --- |
| Базовый | Первые рабочие операции, основные команды и понятия |
| Средний | Типовые рабочие сценарии и сочетание нескольких возможностей |
| Продвинутый | Сложные случаи, конкурентность, оптимизация и эксплуатация |

У больших тем начинай с краткого `README.md`: его быстрый поиск ведёт к подробным страницам.
Требования и ограничения примера указываются рядом с ним на любом уровне.

У каждой темы одно основное место: SQL и особенности СУБД — в `databases/`, библиотеки доступа
к БД из Python — в `python/databases/`, Git и GitHub — в `tools/`. Смежные темы связаны ссылками.

Схемы Mermaid показывают взаимодействия и зависимости; GitHub отображает их прямо в Markdown.
Подробнее об отображении: [диаграммы в GitHub Markdown](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams).
В редакторе без поддержки Mermaid виден исходный текст схемы. Теоретическая схема не является
измерением производительности или доказательством свойств всей системы.
