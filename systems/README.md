# Операционные системы

[Найти пример по задаче или синониму](../tasks/README.md#linux-и-оболочка) — файлы, права, процессы, сеть и службы.

Раздел описывает оболочку, файловую систему, процессы, сеть и службы операционных систем.
Команды общего назначения и административные операции имеют разные последствия и предпосылки.

| Тема | Что содержит |
| --- | --- |
| [Linux](linux/README.md) | Bash, файлы, права, процессы, [поиск процесса по порту](linux/process-by-port.md), сеть, systemd и пакеты |

Для каждой команды учитывайте ОС, реализацию утилиты и дистрибутив.
Проверка переносимой команды Bash на macOS не подтверждает работу GNU-флагов, ядра Linux или systemd.
Полные учебные скрипты используют временные файлы и собственные дочерние процессы.
