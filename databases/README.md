# Базы данных

[Найти пример по задаче или синониму](../tasks/README.md#базы-данных-и-sql) — SQL, ORM, PostgreSQL, SQLite и Redis.

SQL и особенности конкретных СУБД: запросы, структура данных и работа с самой базой.
Библиотеки доступа к БД из Python находятся в [разделе Python](../python/README.md),
в частности [SQLAlchemy](../python/databases/sqlalchemy/README.md).

## Материалы

| Тема | Содержание | Статус |
| --- | --- | --- |
| [SQL](sql/README.md) | Общие запросы и явно обозначенные различия диалектов | Актуализировано |

Общий SQL хранится отдельно от особенностей СУБД. SQLite относится к реляционным базам;
«встраиваемая» описывает способ работы. Redis сгруппирован как нереляционное хранилище.
Диалекты, версии, выполненные сценарии и непроверенные серверные операции указаны в паспортах.
