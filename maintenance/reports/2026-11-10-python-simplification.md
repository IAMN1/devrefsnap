- После редакторских изменений отдельно не повторялись JWT, deployment, расширенная загрузка отношений и потоковое чтение.
- Для Alembic проверено первое создание схемы; последующие миграционные фрагменты, downgrade и восстановление не повторялись.
- Проверки минимальной подготовки использовали синтетические данные и SQLite; PostgreSQL, другие драйверы и рабочие БД не затрагивались.
- Сервер Uvicorn и контейнер не запускались. Тестовые HTTP-запросы выполнялись внутри процесса.
- Проверка компиляции не является статической проверкой типов и не подтверждает runtime-поведение всех фрагментов.
- Официальные API и release notes повторно не исследовались: версии библиотек и код этого этапа не обновлялись.
- Удобство чтения на пользователях не измерялось. Это редакторское упрощение по согласованным признакам перегруза.
- Общий checker и независимое ревью всего этапа выполняет координатор; их результат не приписан этому отчёту заранее.
