# Как устроены шпаргалка, методичка и полный пример

22 ноября 2026 года сравнили материалы их авторов по трём поисковым задачам. Для Docker требовалось собрать проект с Dockerfile в подкаталоге и объяснить, почему сборка может пропустить нужный файл. Для Python искали значение по отсутствующему ключу. Для shell выбирали файл с наименьшим числом строк. Проверяли путь от указанной страницы до ответа, предпосылки и способ распознать результат.

Для нашей карточки достаточно указать исходный каталог и команду `docker build -f dockers/Dockerfile .`. Точка выбирает текущий каталог как контекст. Из того же каталога `COPY main.py .` берёт исходный файл. Для вопроса «Почему файл исчез из сборки?» полезен другой вход. Методичка показывает дерево, применяет правило к одному пути и проверяет исключения. Полный пример даёт оба файла конфигурации и наблюдаемое поведение программы. ## Проверка на Python и shell

**Python.** В Learn X in Y Minutes читатель открывает Python и ищет `filled_dict.get`. Выражения подряд показывают значение для известного ключа, `None` и явно переданное значение по умолчанию. Словарь создан выше. В том же блоке обращение по отсутствующему ключу намеренно вызывает `KeyError`. В отдельном скрипте такой фрагмент прервёт выполнение. Для карточки стоит задать словарь на месте. В комментарии уместно указать значение выражения. Если читатель запускает файл и должен увидеть это значение, нужен `print`. [Исходник обзора](https://github.com/adambard/learnxinyminutes-docs/blob/78548dd09e4e5e9bd9ee235e3d59b43dfeccea05/python.md?plain=1#L291-L329) · [Справка Python 3.14 о dict.get](https://docs.python.org/3.14/builtins/stdtypes.html#dict.get)

**Shell.** В уроке Software Carpentry раздел Combining multiple commands соединяет `wc`, `sort` и `head`. Урок задаёт учебные файлы и показывает вывод после добавления очередной команды. По строке с `methane.pdb` читатель видит, какую задачу решил конвейер. Затем задание предлагает выбрать команду для трёх файлов. Переход сразу к готовой команде пропускает подготовку данных. В нашем практикуме ссылка на данные и текущий каталог нужны рядом с запуском. В шпаргалке хватит короткого конвейера и условия, при котором результат имеет смысл. [Данные урока и исходная задача](https://swcarpentry.github.io/shell-novice/04-pipefilter.html#main-content) · [Конвейер и упражнение](https://swcarpentry.github.io/shell-novice/04-pipefilter.html#combining-multiple-commands)

## Решения для DevRefSnap

Diátaxis различает обучение через действие, решение рабочей задачи, поиск точного факта и объяснение причин. В DevRefSnap читатель может войти в одну тему с любой из этих целей. Название ссылки должно сообщать, какой результат ждёт его после перехода. [Четыре потребности в Diátaxis](https://diataxis.fr/start-here/#the-four-kinds-of-documentation)

| Вопрос читателя | Что перенесли в шаблоны |
| --- | --- |
| «Как это записать?» | Заголовок по действию, минимальный фрагмент, условие применения и ожидаемое значение. Для команды с путём указываем каталог запуска. Подготовку большого проекта выносим по прямой ссылке. [Шпаргалка](../../templates/cheat-sheet.md) |
| «Почему так получилось?» | Берём один пример. На конкретных данных объясняем причинную связь. Меняем одно условие и разбираем результат. Дерево оправдано, когда без него трудно разрешить путь. [Методичка](../../templates/guide.md) |
| «Можно посмотреть всё и запустить?» | Сразу даём исходники, условия запуска и команду проверки. Для случайных идентификаторов, портов и счётчиков описываем устойчивый признак. Сверяем опубликованные блоки с общим файлом. [Полный пример](../../templates/standalone-example.md) |
| «Как изменить уже работающую систему?» | Указываем исходное состояние, последствия, проверку и путь при отказе. Эти сведения нужны рядом с соответствующим шагом. [Процедура](../../templates/procedure.md) |

Сравнение основано на чтении указанных страниц и исходников. Время поиска, самостоятельные действия читателей и запуск внешних учебных проектов в этом сравнении не измерялись. Для наблюдений с участниками в репозитории есть [отдельный протокол](../plans/reader-check.md).
