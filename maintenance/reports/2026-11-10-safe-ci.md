Запись сохраняет обоснование границ CI и результаты их проверки на эту дату.
Порядок запуска и ревью находится в [инструкции инструментов](../../scripts/README.md).
Конфигурация находится в [workflow](../../.github/workflows/materials.yml), зависимости — в [lock-файле](../../scripts/requirements-ci.txt).

## Причины ограничений

CI проверяет материалы, включая предложения внешних авторов.
Учебные команды могут удалять данные, менять историю или обращаться к сети.
Поэтому Markdown-код только разбирается и компилируется; примеры и их установки не исполняются.
Синтаксический успех не доказывает правильность, безопасность или результат примера.

Одноразовые GitHub-hosted runners ограничивают сохранение состояния между запусками.
`pull_request` и `push` в `main` используют `contents: read`; checkout не сохраняет credentials.
Полные SHA Actions и hashes зависимостей ограничивают незаметную замену загружаемого кода.
Секреты, кэши, артефакты, self-hosted runners и привилегированные события исключены из этой схемы.
Runner имеет сеть для подготовки; read-only токен не скрывает содержимое разрешённого приватного checkout.

Внешние fork workflows требуют подтверждения; write-токены, secrets и variables им не передаются.
Эти настройки подтверждены обратным чтением API, но независимый fork PR не запускался.
Сигналы diff помогают ревью; они не являются полным детектором атак или сканером секретов.

## Выполненные проверки

Локальная среда: macOS arm64, Python 3.14.7, Bash 3.2.57.
В `/private/tmp/cheat-ci-venv` установлены markdown-it-py 4.2.0, mdurl 0.1.2 и PyYAML 6.0.3.
Использованы wheels с `--require-hashes --only-binary=:all:`.
Закреплённые hashes PyYAML проверены для Linux x86_64 / Python 3.13 и macOS arm64 / Python 3.14.
Другие сочетания платформы и Python не проверялись.

Команды: `python -I scripts/check_materials.py` и `python -I -m unittest discover -s scripts/tests -v`.
Итог: полный checker и 25 тестов прошли локально и после исправлений в GitHub Actions.
Тесты проверяют ссылки и границы путей, синтаксис, отсутствие исполнения контрольного кода и сигналы ревью.

| Воспроизведённый дефект | Исправление и подтверждение |
| --- | --- |
| Legacy-команда runner в JSON-выводе имени файла | `#` кодируется как JSON escape; декодирование сохраняет имя, stdout не содержит legacy-префикса |
| Ложное закрытие fence строкой цитаты | Закрытие учитывает диапазон и содержимое Markdown-токена |
| Пропуск `curl -k` | Сигнал проверен для `-k`, `-ksS`, `-sS -k` |

Регрессионные тесты дали отказ до исправления и успех после исправления.
Дополнительно проверены одиночное ограждение, Git pathspec magic, Unicode-разделитель и EOF без перевода строки.
Независимое ревью выявило первые два дефекта и TLS-пропуск; повторного полного ревью после исправлений не было.
Реальная legacy-инъекция в Actions намеренно не выполнялась.

[PR №1](https://github.com/IAMN1/Python_cheat_sheet/pull/1) прошёл [финальный PR-run](https://github.com/IAMN1/Python_cheat_sheet/actions/runs/42781301048)
и [post-merge run](https://github.com/IAMN1/Python_cheat_sheet/actions/runs/42781461498).
Оба задания `materials-static` и `checker-tests` успешны.
Первый runner подтвердил CPython 3.13.18, образ ubuntu-24.04 `20261101.360.1` и права Contents/Metadata read.

[Снимок API](2026-11-10-safe-ci-github.json) сохраняет точные разрешённые SHA, права, run/job URL и ответы HTTP 403.
Его SHA относятся к истории до [замены сообщений](2026-11-10-simplification-publication.md).
Значения секретов не запрашивались.

## Защита main

На дату снимка репозиторий приватный, единственный сопровождающий — `IAMN1`.
GitHub вернул `protected: false` и HTTP 403 для branch protection/rulesets из-за текущего тарифа.
Обязательные PR, status checks, запрет force push и удаления `main` не включены.
CODEOWNERS обозначает владельца, но не обеспечивает принудительное одобрение.
Пользователь выбрал сохранить тариф и приватность; действует ручной контроль владельца.
Единственному сопровождающему нельзя требовать самоодобрение собственного PR.

[Напоминание перед публичной публикацией](../plans/public-release.md) сохраняет отдельную очередь настройки защиты.
Независимый fork, отказ подтверждения и попытка записи чужим токеном не воспроизводились.
Выполнение учебных программ, SQL, сетевых команд и безопасность всех внешних адресов этим CI не проверялись.
