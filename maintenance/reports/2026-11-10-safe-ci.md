## Границы доказательств

Markdown и учебные команды не исполняются.
Python проверяется компиляцией; Bash проверяется только разбором синтаксиса.
Синтаксический успех не подтверждает зависимости, смысл, безопасность или результат примера.
SQL, Redis, PostgreSQL, Docker и сетевые команды в этом этапе не выполняются.
Сигналы ревью не являются сканером секретов, проверкой ссылок в сети или детектором всех атак.
Фактический fork PR от независимого аккаунта в этом этапе ещё не проверялся.
Наличие read-only токена не скрывает содержимое приватного репозитория от разрешённого workflow.
Не добавляйте к этому CI секреты или привилегированный обработчик непроверенных артефактов.

## Защита main

Защита ветки и rulesets недоступны на текущем тарифе приватного репозитория.
Обязательные status checks, запрет прямого push, force push и удаления `main` не включены.
CODEOWNERS обозначает владельца критических файлов, но не обеспечивает принудительное одобрение.
Действует ручной контроль единственного владельца с правом записи.
Публичность, тариф и состав collaborators не изменены.

## Реализованные ограничения Actions

GitHub API принял изменения и подтвердил их обратным чтением 2026-11-10.

| Настройка | Фактическое значение |
| --- | --- |
| Actions | Включены; разрешены только два точных SHA |
| Обязательное закрепление Actions SHA | `sha_pinning_required: true` |
| Разрешённый checkout | `actions/checkout@11d5960a326750d5838078e36cf38b85af677262` |
| Разрешённый setup-python | `actions/setup-python@ece7cb06caefa5fff74198d8649806c4678c61a1` |
| Остальные GitHub-owned и verified Actions | Не разрешены автоматически |
| Права токена по умолчанию | `read` |
| Одобрение PR из Actions | `can_approve_pull_request_reviews: false` |
| Workflow из fork PR приватного репозитория | Разрешены с обязательным подтверждением |
| Write-токены для fork PR | `false` |
| Secrets и variables для fork PR | `false` |
| Подтверждение внешнего fork workflow | `require_approval_for_fork_pr_workflows: true` |

Public-only endpoint `fork-pr-contributor-approval` вернул HTTP 422 для приватного репозитория.
Использован соответствующий endpoint `fork-pr-workflows-private-repos`.
Политика подтверждения прочитана обратно; реальный PR из независимого fork не запускался.
