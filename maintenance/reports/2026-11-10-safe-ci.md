## Причины ограничений

CI проверяет материалы, включая предложения внешних авторов.
Учебные команды могут удалять данные, менять историю или обращаться к сети.
Поэтому Markdown-код только разбирается и компилируется; примеры и их установки не исполняются.
Синтаксический успех не доказывает правильность, безопасность или результат примера.

Одноразовые GitHub-hosted runners ограничивают сохранение состояния между запусками.
`pull_request` и `push` в `main` используют `contents: read`; checkout не сохраняет credentials.
Полные SHA Actions и hashes зависимостей ограничивают незаметную замену загружаемого кода.
Секреты, кэши, артефакты, self-hosted runners и привилегированные события исключены из этой схемы.
Runner имеет сеть для подготовки; read-only токен не скрывает содержимое разрешённого приватного checkout.

Внешние fork workflows требуют подтверждения; write-токены, secrets и variables им не передаются.
Эти настройки подтверждены обратным чтением API, но независимый fork PR не запускался.
Сигналы diff помогают ревью; они не являются полным детектором атак или сканером секретов.

## Защита main

На дату снимка репозиторий приватный, единственный сопровождающий — `IAMN1`.
GitHub вернул `protected: false` и HTTP 403 для branch protection/rulesets из-за текущего тарифа.
Обязательные PR, status checks, запрет force push и удаления `main` не включены.
CODEOWNERS обозначает владельца, но не обеспечивает принудительное одобрение.
Пользователь выбрал сохранить тариф и приватность; действует ручной контроль владельца.
Единственному сопровождающему нельзя требовать самоодобрение собственного PR.

Защиту настроили позднее при [публичном релизе DevRefSnap](#публичный-релиз-devrefsnap).
Независимый fork, отказ подтверждения и попытка записи чужим токеном не воспроизводились.
Выполнение учебных программ, SQL, сетевых команд и безопасность всех внешних адресов этим CI не проверялись.

### Проверка перед публикацией — 13 ноября 2026

GitHub API подтвердил приватную видимость, роль администратора у `IAMN1` и `protected: false` для `main` на `e2dc575`. Список сопровождающих содержит только `IAMN1`.
Запросы защиты ветки, списка rulesets и действующих правил для `main` вернули HTTP 403. GitHub требует GitHub Pro или публичную видимость.
На этом коммите оба задания `materials-static` и `checker-tests` завершились с `success`. Источник обеих проверок — GitHub Actions, ID приложения `15368`. [Запуск CI](https://github.com/IAMN1/devrefsnap/actions/runs/43320078426)

GitHub API подтвердил ограничение Actions выбранными полными SHA, права токена только на чтение и запрет одобрения PR из workflow.
Для приватных форков включено подтверждение запуска. GitHub не передаёт им токены с правом записи, секреты или переменные.
Запрос политики подтверждения для публичных форков вернул HTTP 422 для приватного репозитория. Политику проверили после [смены видимости](#публичный-релиз-devrefsnap). [Настройки GitHub Actions](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/enabling-features-for-your-repository/managing-github-actions-settings-for-a-repository)

- Для обновления `main` требуется PR. Обязательных одобрений — 0. CODEOWNERS обозначает критические файлы для ручного ревью владельцем.
- Обязательные проверки `materials-static` и `checker-tests` должны пройти на актуальной базе. Допустимый источник результатов — GitHub Actions, ID `15368`.

- Политика `all_external_contributors` требует разрешения на запуск workflow из внешнего форка. GitHub сохранил ограничение на выбранные полные SHA Actions и режим `GITHUB_TOKEN` по умолчанию `read`. Этот токен не может одобрять PR.
