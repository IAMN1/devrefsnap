## Границы доказательств

Markdown и учебные команды не исполняются.
Python проверяется компиляцией; Bash проверяется только разбором синтаксиса.
Синтаксический успех не подтверждает зависимости, смысл, безопасность или результат примера.
SQL, Redis, PostgreSQL, Docker и сетевые команды в этом этапе не выполняются.
Сигналы ревью не являются сканером секретов, проверкой ссылок в сети или детектором всех атак.
Фактический fork PR от независимого аккаунта в этом этапе ещё не проверялся.
Наличие read-only токена не скрывает содержимое приватного репозитория от разрешённого workflow.
Не добавляйте к этому CI секреты или привилегированный обработчик непроверенных артефактов.

До исправлений ревьюер не рекомендовал слияние.

| Замечание | Подтверждение | Исправление |
| --- | --- | --- |
| Important: legacy-команда runner внутри JSON | Имя `##[error]INJECTED.md` попадало в stdout | Оба CLI кодируют `#` как JSON escape во всех полях |
| Important: ложное закрытие fence | Строка `> ``` ` внутри блока давала успех | Закрытие определяется диапазоном и содержимым токена Markdown |
| Пропущенный TLS-сигнал | `curl -k` и объединённые флаги не выделялись | Исправлено выражение; проверены `-k`, `-ksS` и `-sS -k` |

Регрессионные тесты воспроизвели все три замечания до исправления.
Дополнительные тесты проверяют `##[add-mask]`, `##[stop-commands]`, ложный отступ закрытия, цитату, список, Unicode-разделитель и EOF без перевода строки.
Тесты показывают, что декодированный JSON сохраняет имя, а stdout не содержит legacy-префикса.
Unicode-разделитель внутри кода не считается отдельной строкой Markdown.

Поведение legacy-команд сверено с [ActionCommand](https://github.com/actions/runner/blob/main/src/Runner.Common/ActionCommand.cs) и [ActionCommandManager](https://github.com/actions/runner/blob/main/src/Runner.Worker/ActionCommandManager.cs).

Повторное независимое ревью после исправлений не проводилось; исправления проверены регрессионными тестами и новым CI-прогоном.

После исправлений локально проходят 25 тестов.

### Оставшиеся ограничения

GitHub по-прежнему возвращает `protected: false` для `main` и HTTP 403 для branch protection/rulesets.
Обязательные PR, status checks, запрет force push и удаления ветки отсутствуют.
Ручной контроль единственного владельца не является технической защитой ветки.
CODEOWNERS не принуждает к одобрению на текущем тарифе.

Внешний fork PR, отказ подтверждения внешнего запуска и попытка записи чужим токеном не воспроизводились на независимом аккаунте.
Вместо этих сценариев проверены настройки API, конфигурация workflow и фактические read-only права токена в логах.
Выполнение учебных программ, смысл советов, SQL и безопасность каждого внешнего адреса остаются отдельными проверками.
Другие архитектуры runner и другие сочетания Python/PyYAML wheels не проверялись.
