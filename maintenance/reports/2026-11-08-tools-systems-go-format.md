## Непроверенные сценарии и границы

- Полный запуск `port_probe.py`, Linux `ss/ip/nsenter`, PID/network namespace и ограничения `/proc` не выполнены.
  В окружении macOS нет `ss`; Docker daemon не запущен.
  Исходный пример сохранён; его Python-синтаксис проверен отдельно от Linux runtime.
- Shell-скрипты файлов и процессов выполнены на macOS; это не доказывает поведение всех GNU/Linux-дистрибутивов и утилит.
- Systemd start/stop/restart/enable, установка и удаление пакетов, SSH, firewall и маршруты не изменялись.
  Эти фрагменты требуют отдельной учебной Linux-системы.
- Создание, готовность, review, CI и merge настоящего GitHub PR не выполнялись.
  CLI проверен через help и официальную документацию; публикации нет.
- Go HTTP проверен внутри процесса; TLS, proxy, настоящий сервер, нагрузка и отмена внешних запросов не проверены.
- Worker pool проверяет уже отменённый context; детерминированная проверка отмены посреди операции и подсчёт всех возможных утечек отсутствуют.
- Race detector проверил выполненные пути на darwin/arm64; он не доказывает отсутствие всех гонок и deadlock.
- Редакторская проверка первого экрана и маршрутов не является исследованием с читателями.
