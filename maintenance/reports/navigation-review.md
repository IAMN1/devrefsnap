# Решения по структуре и навигации

Решения приняты при переработке справочника 2026-11-06–10.
Действующие требования находятся в [AGENTS.md](../../AGENTS.md) и [шаблонах](../../templates/README.md).

| Решение | Причина |
| --- | --- |
| Каталог технологий и указатель задач с синонимами | Читатель может помнить инструмент или только симптом проблемы |
| Короткая карточка ведёт прямо к полному примеру | Повторение синтаксиса и первый самостоятельный запуск требуют разной глубины |
| Шпаргалка, полный пример и процедура имеют разные шаблоны | Процедуре нужны порядок и проверка отказа; карточке нужен быстрый выбор |
| Уровни, оглавления и чек-листы добавляются по роли | Обязательный общий каркас повторял навигацию и assertions |
| Подготовка относится к выбранной задаче | Независимые примеры не должны требовать весь стек темы |
| Проверки и служебная история отделены от шпаргалок | Читателю нужны условия запуска и ограничения рядом с командой |

Самостоятельный SQLAlchemy N+1 использует две синхронные модели без общей схемы с `AsyncAttrs`.
Расширенная лабораторная сохраняет общую схему и её зависимость `greenlet`.
FastAPI разделяет CRUD, файлы, middleware и тестовые комплекты.
Backup/restore SQLite отделён от миграции схемы.
Полные программы Go и Outbox доступны из карточек по прямым ссылкам.
На этапе переноса прежний путь `python/architecture/project-design.md` вёл к новому каталогу.

Исходная методичка проектирования распределена по трём задачам:
[решения и структура](../../docs/ru/python/architecture/project-design/structure-and-decisions.md),
[полный пакет](../../docs/ru/python/architecture/project-design/example.md),
[поставка и изменения](../../docs/ru/python/architecture/project-design/delivery-and-evolution.md).
Общие принципы находятся в [архитектуре](../../docs/ru/architecture/README.md).
