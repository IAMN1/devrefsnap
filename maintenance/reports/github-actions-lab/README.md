Здесь сохранены полные журналы трёх запусков от 12 ноября 2026 года. Журналы подтверждают результаты из [отчёта о проверках](../general-checks.md#проверка-на-github).

ZIP-файлы сохранены в исходном виде из GitHub API. Каждый ZIP содержит полный журнал задания и системный журнал runner. Файл `.log` побайтово совпадает с полным журналом задания внутри соответствующего ZIP.

[Манифест](manifest.json) содержит исходные идентификаторы запусков, SHA коммитов, время UTC, результаты заданий и шагов. Манифест также содержит размеры и SHA-256 архивов, их файлов и читаемых журналов.

При выгрузке проверены CRC всех ZIP-файлов, SHA-256 сохранённых файлов и побайтовое совпадение журналов с содержимым архивов. Проверены ожидаемый отказ, успешный повтор и обе строки `OK GET` из проверки API.

GitHub маскирует токен доступа в исходных журналах. Значение `lab-only-password` относится к одноразовой учебной БД с синтетическими данными. Архив не содержит действующих учётных данных этой БД; учебное окружение завершило работу после запуска.

Журналы сохраняют сведения о среде запуска 12 ноября. Новые версии зависимостей и повторный запуск workflow при переносе не проверялись. Ветки диагностики сквозного workflow после отказа на GitHub отдельно не выполнялись.
