# Внутренние ссылки на GitHub

22 ноября 2026 года проверили все 299 Markdown-файлов опубликованного коммита `3bd6c05`. В выборку вошли читательские страницы, шаблоны, служебные материалы и файлы в `.github/`. [Дерево проверенного коммита](https://github.com/IAMN1/devrefsnap/tree/3bd6c05c1dab025287ab27822067ed21cdd4b358)

| Что проверили | Наблюдение |
| --- | --- |
| Файлы назначения | Все 5166 локальных ссылок и встраиваний изображений в исходниках ведут к одному из 500 файлов этого коммита. Регистр пути совпал с деревом Git. |
| Ссылки в опубликованной разметке | Сопоставили исходные адреса с атрибутами `href` и `src` в HTML, который GitHub вернул для каждого файла по SHA. Все адреса совпали после разрешения путей. GitHub дополнительно обернул 40 изображений ссылками на файлы. |
| Ссылки на разделы | Для 2899 ссылок проверили 1030 разных сочетаний файла и фрагмента. У всех есть целевой `id` или `name` на GitHub. Сверили 1884 якоря заголовков и 929 пользовательских якорей, включая кириллицу и заголовки с кодом. |
| Изображения | Получили все 15 SVG и 11 GIF по опубликованным адресам `src`. Все запросы вернули HTTP 200 и файлы, побайтово совпадающие с Git. В SVG нет ссылок на дополнительные ресурсы. |
| Переход в браузере | В Chromium открыли из таблиц три ссылки: лабораторную C++ на другой странице, пользовательский якорь на странице N+1 и русский заголовок на странице Actions. Во всех случаях фрагмент появился в адресной строке, а элемент назначения попал в область просмотра. |

На страницах [C++](../../docs/en/cpp/tooling-and-testing.md#run-the-lab) и [C#](../../docs/en/csharp/practice.md#application-areas) ручной якорь повторял имя соседнего заголовка. GitHub создал по два элемента с одинаковым `id`. Удалили ручные якоря. Заголовки сохраняют оба адреса.

Прежняя проверка возвращала 0 ошибок на исходном коммите. Новая проверка обнаружила оба совпадения в том же дереве. Четыре регрессионных теста проверяют совпадение с заголовком, повтор имени между HTML-элементами, неверный регистр пути и ссылку от корня репозитория. На macOS с Python 3.14.7 и markdown-it-py 4.2.0 до исправления все четыре теста воспроизводили расхождения. После исправления прошли все 26 тестов проверки материалов. ### Старые закладки

В PR №11 удалили 103 страницы перехода в семи корневых каталогах. Например, адрес `python/architecture/project-design.md` на `main` стал возвращать 404, хотя методичка оставалась в языковых каталогах. При проверке 22 ноября страницы перехода восстановили по дереву предыдущего коммита. Они содержат ссылки на актуальные материалы и прежние якоря. Полный учебный текст по-прежнему редактируется в языковых версиях.
