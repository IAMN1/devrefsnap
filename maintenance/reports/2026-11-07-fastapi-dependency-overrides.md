## Проверка понятности

Редакторский маршрут: корневой каталог → указатель задач → карточка → самостоятельный пример.
Дополнительный вход: быстрый поиск FastAPI → самостоятельная программа.

| Вопрос читателя | Где находится ответ |
| --- | --- |
| Как найти пример без знания dependency_overrides? | Указатель содержит задачу проверки без реальной зависимости и слова «без сети», «без БД» |
| Какую функцию подменять? | Карточка и раздел выбора называют исходный объект из Depends |
| Нужны ли другие приложения раздела? | Минимальный файл содержит приложение, маршрут, зависимость и оба теста |
| Почему подмена возвращает None? | Маршрут использует зависимость как проверку; результат обработчику не передаётся |
| Что произойдёт после теста? | Finally восстанавливает весь прежний словарь; последующий запрос проверяет действие восстановления |
| Что произойдёт при исключении? | Расширенный сценарий проверяет ошибку assert и RuntimeError из подмены |

Это редакторская проверка и независимое ревью агентом, а не исследование с реальными читателями.
Понятность для начинающих пользователей экспериментально не измерялась.

## Существенные ограничения

- Пример показывает механизм на проверке заголовка; настоящий сервер БД и внешний провайдер не используются.
- Подмена результата, передаваемого в обработчик, объяснена, но отдельный пример с сессией БД не добавлен.
- Конкурентное изменение одного app, async-клиенты и зависимости с yield не проверены.
- Тесты выполняют HTTP-запросы внутри процесса; реальные сеть, сервер и развёртывание не проверяются.
- Независимые читатели не участвовали; результаты программных тестов не доказывают понятность текста.
