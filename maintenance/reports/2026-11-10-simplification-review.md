## Подтверждённые замечания

### 1. [P2] Установите зависимости общей модели в самостоятельном Alembic-примере

Место первоначального замечания: `python/databases/sqlalchemy/async-and-operations.md:223–225`; импорт модели — `python/databases/sqlalchemy/models-and-transactions.md:37`.

Сценарий читателя: выберите «Изменить схему» в первом экране; создайте чистое окружение; установите только указанный Alembic; скопируйте `demo_models.py`; выполните autogenerate. Общая модель импортирует `AsyncAttrs`, поэтому одного Alembic недостаточно для указанного SQLAlchemy 2.1.8 без `greenlet`.

Ошибка подтверждена адресным запуском уже скачанного SQLAlchemy 2.1.8 в отдельном существующем временном Python-окружении без `greenlet`. Команда использовала `python -B`, добавляла только каталог этого SQLAlchemy в `sys.path` и импортировала `AsyncAttrs`. Получен `ImportError: The SQLAlchemy asyncio module requires that the Python 'greenlet' library is installed` с указанием установить `sqlalchemy[asyncio]`. Пакеты при ревью не устанавливались.

Исправление: дайте одну команду `python -m pip install 'sqlalchemy[asyncio]==2.1.8' 'alembic==1.20.1'`; свяжите подготовку напрямую с общей схемой; объясните необходимость extra. Уберите соседний повторный unpinned `pip install alembic`. Для проверки достаточно нового учебного проекта и цепочки initial revision → upgrade → проверка схемы; рабочая БД не нужна.

Это оставшаяся неполнота прежней подготовки, которую должен закрыть текущий этап самостоятельных установок. Замечание не означает регресс кода модели.

### 2. [P2] Ограничьте запуск проверки событий выбранным тестовым файлом

Место: `python/databases/sqlalchemy/async-and-operations.md:199`.

Новая подготовка событий на строках 134–135 говорит, что `aiosqlite` и Alembic не нужны. Старая команда `python -m pytest -q -o asyncio_default_fixture_loop_scope=function` при этом запускала все найденные тесты темы. Если в учебной папке уже сохранён соседний `test_async.py`, команда захватывает async-задачу, для которой нужны другие зависимости. Читатель не может выполнить указанную общую проверку только с выбранным набором событий.

Исправление: используйте `python -m pytest -q test_observe.py`. Для этого синхронного теста параметр области async-фикстур не нужен. Проверьте только этот модуль в окружении общей модели без `aiosqlite`, Alembic и pytest-asyncio.

Оба замечания переданы координатору. Проверка конечного текста уже показала адресную команду на строке 199 и новую pinned установку Alembic на строке 232. Результаты исполнения исправленной подготовки в первичный вердикт не включены.
