# Сопровождение репозитория

Здесь находятся материалы для авторов и агентов, которые поддерживают шпаргалки.
Учебные материалы находятся в [основном каталоге](../README.md).

[Запуск статических проверок и ревью внешнего PR](../scripts/README.md).

| Каталог | Назначение |
| --- | --- |
| [reports](reports/README.md) | Результаты проверок, ревью и история изменений |
| [plans](plans/README.md) | Порученные задачи и предложения по развитию |

В отчёте укажите исходную страницу, дату, среду и фактически выполненные действия.
Отделяйте проведённую проверку от предложения проверить сценарий позже.
Не переносите эти записи в учебный текст.
В шпаргалках сохраняйте зависимости, ожидаемый результат, технические ограничения и источники.
