# Напоминание перед публичной публикацией

Пользователь попросил напомнить о защите `main`, когда репозиторий станет публичным.
На 2026-11-10 репозиторий приватный; текущий тариф не поддерживает branch protection и rulesets.
Тариф и публичность сохраняются до отдельного поручения.

## При подготовке или выполнении перевода в публичный режим

- [ ] Напомните пользователю, что обязательные PR и проверки сейчас не обеспечены правилами GitHub.
- [ ] Проверьте доступные правила и текущие права GitHub.
- [ ] Потребуйте PR и успешные `materials-static` и `checker-tests` на актуальном состоянии.
- [ ] Запретите force push и удаление `main`.
- [ ] Настройте контроль критических файлов с учётом CODEOWNERS и состава сопровождающих.
- [ ] Сохраните возможность единственному сопровождающему слить собственный проверенный PR без самоодобрения.
- [ ] Проверьте ограничения внешних workflow-запусков для публичного репозитория.
- [ ] Перечитайте применённые настройки API и сохраните результат в отчёте.

Это напоминание к этапу публикации; у него нет календарной даты.
