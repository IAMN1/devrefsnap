## Решения и границы

- Используйте `pull_request` для PR в `main` и `push` для `main`.
- Используйте одноразовый `ubuntu-24.04`, Python 3.13 и токен `contents: read`.
- Закрепите Actions полными SHA, зависимости — версиями и SHA256.
- Не запускайте Markdown, Python-примеры, установки из примеров или команды Bash.
- Разбирайте Markdown через `markdown-it-py`; проверяйте Python через `compile`, Bash через `bash -n` с пустым окружением.
- Проверяйте локальные ссылки, якоря, языки и закрытие ограждений.
- Выводите сигналы ревью по добавленным строкам: адреса, зависимости, сеть, TLS, опасные команды, критические файлы.
- Сигнал требует проверки смысла и не означает вредоносность.
- Не используйте секреты, кэши, артефакты, self-hosted runners или привилегированные события.
- Добавьте CODEOWNERS для `.github/`, `scripts/`, `AGENTS.md` и `templates/`.
