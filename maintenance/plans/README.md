# Очередь работ

## Предложения

- Проверить поиск рецепта, выбор приёма и понимание последствий с читателями разного опыта.
- Просмотреть остальные темы на скрытые предпосылки и тяжёлую общую подготовку.
- Оценить необходимость браузерного поиска после проверки существующей навигации.
- Рассмотреть дополнительные эксплуатационные проверки резервного копирования как отдельные задачи.

Подробности прежних предложений находятся в [историческом обзоре](../reports/navigation-review.md#предложения-по-понятности-и-подготовке).
При добавлении задачи в указатель обновляйте прямые ссылки и используйте слова, которыми читатель описывает проблему.
