## Проверить удобство с читателями

Проверка с читателями ещё не проводилась.
Редакторские обзоры и успешные тесты программ не измеряют скорость поиска и понимание текста.

- Проверьте поиск рецепта без названия API через указатель задач и синонимов.
- Проверьте выбор приёма и понимание последствий у читателей разного опыта.
- Оцените необходимость браузерного поиска после наблюдений за существующей навигацией.

Для наблюдений зафиксируйте просмотрщик, ширину окна и начальную страницу.
Запишите время до выбора рецепта, переходы, возвраты и ошибки.
Попросите читателя объяснить результат и последствия команды.
При сравнении вариантов меняйте порядок задач, чтобы учесть запоминание.

| Задача | Признак успеха |
| --- | --- |
| Git | Различены индекс, рабочая папка, локальный и опубликованный коммит |
| Восстановление БД | Выбраны отдельная цель и проверки восстановленных данных |
| SQLAlchemy N+1 | Выбрана стратегия загрузки с подходящими ограничениями |
| FastAPI | Выбрана исходная зависимость; понятен порядок восстановления overrides |
| Linux: порт | Учтены namespace и права при поиске владельца сокета |

## Дополнительные эксплуатационные проверки БД

Эти сценарии не выполнялись в прежних учебных проверках.
Для каждого сценария нужно отдельное изолированное окружение с синтетическими данными.

| Предложение | Проверяемый результат |
| --- | --- |
| Копия при ограниченном конкурентном writer | Согласованные связанные строки после восстановления PostgreSQL и SQLite |
| Перенос владельцев и ACL PostgreSQL | Разрешённый SELECT и запрещённый INSERT у синтетических ролей |
| PITR PostgreSQL | Отдельный кластер восстановлен к точке до учебного удаления |
| Остановка во время записи | Сохранены завершённые транзакции; незавершённые изменения отсутствуют после запуска |

Прежний логический restore исключает владельцев и ACL через `--no-owner --no-privileges`.
PITR требует физической копии и цепочки WAL; `pg_dump` не заменяет этот механизм.
Остановка процесса не воспроизводит все последствия сбоя питания или повреждения носителя.
Источники: [PostgreSQL PITR](https://www.postgresql.org/docs/18/continuous-archiving.html), [pg_restore](https://www.postgresql.org/docs/18/app-pgrestore.html), [SQLite backup API](https://www.sqlite.org/backup.html).
