<a id="values"></a>

## Значения и циклы

Используйте `int` для небольших целых чисел, `double` для приближённых вычислений и `bool` для условий. Инициализируйте локальные переменные при объявлении. `auto` выводит тип из выражения и сохраняет статическую типизацию.

Фрагмент для тела функции. Подключите `<cstddef>` и `<vector>`.

```cpp
const std::vector<int> scores{55, 60, 95};
const auto minimum = 60;
std::size_t count{};
for (int score : scores) {
    if (score >= minimum) {
        ++count;
    }
}
```

Тип `minimum` здесь — `const int`. Цикл копирует по одному `int`, а `count` становится равен 2. Если элементы дороги в копировании, используйте `const auto&` для чтения. Для изменения элементов изменяемой коллекции используйте `auto&`. [Полный первый пример](../../../examples/cpp/basics.cpp).

<a id="parameters"></a>

## Значения, ссылки и `const`

| Намерение функции | Тип параметра | Условие |
| --- | --- | --- |
| Получить маленькое значение | `int value`, `bool flag` | Функция получает своё значение. |
| Прочитать дорогой в копировании объект | `const T& value` | Функция читает через ссылку. |
| Изменить объект вызывающего кода | `T& value` | Передайте изменяемый объект. |
| Принять адрес необязательного объекта | `const T* value` | Проверьте `nullptr` перед разыменованием. |
| Прочитать непрерывную последовательность | `std::span<const int> values` | Память элементов должна оставаться доступной. |
| Принять владение ресурсом | `std::unique_ptr<T> resource` | Вызов передаёт владение. |

`const T*` ограничивает изменение объекта через указатель. `T* const` запрещает назначить указателю другой адрес. `const T&` ограничивает изменение через эту ссылку. `auto copy = value` обычно создаёт значение, а `auto& alias = value` связывает имя с существующим объектом.

Фрагмент объявления. Подключите `<span>`. `ScoreSummary` — структура с двумя счётчиками из [заголовка проекта](../../../examples/cpp/score-summary.hpp).

```cpp
ScoreSummary summarize_scores(std::span<const int> scores, int minimum);
```

Передайте массив или вектор с элементами типа `int`. Функция получает представление и возвращает два счётчика по значению. [Реализация](../../../examples/cpp/score-summary.cpp) использует представление только во время вызова.

## Классы и инварианты

Храните поле в `private`, если конструктор и методы должны поддерживать допустимое состояние. Добавьте `const` к методу чтения.

Фрагмент определения класса. Подключите `<stdexcept>`.

```cpp
class ScoreLimit {
public:
    explicit ScoreLimit(int value) : value_{value}
    {
        if (value < 0 || value > 100) {
            throw std::invalid_argument{"limit must be in [0, 100]"};
        }
    }

    [[nodiscard]] bool accepts(int score) const
    {
        return score >= value_;
    }

private:
    int value_;
};
```

`ScoreLimit{60}.accepts(60)` возвращает `true`. Конструктор проверяет порог, а `accepts` сравнивает балл с порогом. Ключевое слово `explicit` запрещает неявное преобразование `int` в `ScoreLimit`. Храните готовые результаты подсчёта в `struct`, как в [`ScoreSummary`](../../../examples/cpp/score-summary.hpp).

<a id="templates"></a>

## Шаблоны и ограничения

Объявите шаблон, если одна операция применима к нескольким типам. Ограничьте типы через concept, если у операции есть конкретные требования.

Фрагмент определения функции. Подключите `<concepts>`.

```cpp
template <std::integral T>
constexpr bool at_least(T value, T minimum)
{
    return value >= minimum;
}

static_assert(at_least(60, 60));
```

Компилятор проверяет условие в `static_assert`. Этот шаблон выводит один `T` для обоих аргументов. Вызов `at_least(60, 60L)` требует явно согласовать типы. Обычно поместите определение шаблона в заголовок, чтобы компилятор видел его в месте использования.

<a id="ranges"></a>

## Лямбды и диапазоны

Используйте алгоритм, если нужен готовый результат. Используйте представление, если нужно обойти только подходящие элементы.

Фрагмент для тела функции. Подключите `<algorithm>`, `<ranges>` и `<vector>`.

```cpp
std::vector<int> scores{55, 60, 95};
int minimum = 60;
const auto passes = [minimum](int score) { return score >= minimum; };

const auto count = std::ranges::count_if(scores, passes);
auto passing_scores = scores | std::views::filter(passes);
```

`count` равен 2. При обходе `passing_scores` выдаёт 60 и 95. Захват `[minimum]` копирует порог на момент создания лямбды. Захват по ссылке требует, чтобы объект оставался доступным при вызове. Представление фильтра хранит ссылку на этот вектор и вычисляет совпадения по мере обхода. Сохраняйте вектор живым и соблюдайте правила недействительности его итераторов.

## Выбор средств стандартной библиотеки

| Задача | Заголовок и API | Условие |
| --- | --- | --- |
| Хранить последовательность | `<vector>` `std::vector`, `<array>` `std::array` | `vector` меняет размер. Размер `array` задан в типе. |
| Искать по ключу | `<map>` `std::map`, `<unordered_map>` `std::unordered_map` | `map` хранит порядок ключей. `unordered_map` использует хеширование. |
| Хранить или читать текст | `<string>` `std::string`, `<string_view>` `std::string_view` | `string` владеет содержимым. `string_view` использует существующую память. |
| Сортировать и отбирать элементы | `<algorithm>` `std::ranges::sort`, `std::ranges::find` | Сортировка меняет последовательность. Поиск может вернуть конец диапазона. |
| Представить необязательное значение или один из типов | `<optional>` `std::optional`, `<variant>` `std::variant` | Проверяйте наличие значения или активный тип. |
| Работать с путями, файлами и временем | `<filesystem>` `std::filesystem::path`, `<fstream>` `std::ifstream`, `<chrono>` `std::chrono::steady_clock` | Проверяйте ошибки ввода-вывода. Измеряйте интервалы монотонными часами. |
| Выполнять работу в потоке и защищать данные | `<thread>` `std::jthread`, `<mutex>` `std::scoped_lock` | Определите владельца данных и единый способ синхронизации доступа. |

## Отсутствие результата и ошибки

| Ситуация | Приём | Пример |
| --- | --- | --- |
| Значение может отсутствовать при нормальной работе | `std::optional<T>`, `std::nullopt` | Поиск первого подходящего балла. |
| Аргумент нарушает контракт функции | Типизированное исключение | Учебный проект выбрасывает `std::invalid_argument` для балла вне диапазона. |
| Ошибка — часть протокола API | Код ошибки или объект результата | `std::from_chars` возвращает позицию и `std::errc`. |

Фрагмент функции. Подключите `<optional>` и `<span>`.

```cpp
std::optional<int> first_at_least(std::span<const int> scores, int minimum)
{
    for (int score : scores) {
        if (score >= minimum) {
            return score;
        }
    }
    return std::nullopt;
}
```

Для 55, 60, 95 и порога 60 функция возвращает 60. Для пустого ввода функция возвращает `std::nullopt`. Проверьте наличие значения перед разыменованием. В [консольном примере](../../../examples/cpp/score-count.cpp) проверьте оба поля результата `from_chars`. Функция может принять числовой префикс строки. Консольный адаптер переводит ошибки аргументов в сообщение и код завершения 2.
