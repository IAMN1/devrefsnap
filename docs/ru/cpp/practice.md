<a id="ownership"></a>

## Владение ресурсами

RAII (Resource Acquisition Is Initialization) связывает получение ресурса с созданием объекта. Деструктор освобождает ресурс при выходе из области видимости, в том числе при раскрутке стека из-за исключения. Для файла используйте поток. Для блокировки используйте `std::scoped_lock` из `<mutex>`.

Фрагмент для тела функции. Подключите `<fstream>`, `<stdexcept>` и `<string>`. Переменная `path` содержит путь к текстовому файлу. Файл должен содержать хотя бы одну строку. Первая строка может быть пустой.

```cpp
std::ifstream input{path};
std::string line;
if (!std::getline(input, line)) {
    throw std::runtime_error{"could not read the first line"};
}
```

После успешного чтения `line` содержит первую строку без разделителя строки. Если файл пуст или недоступен, чтение завершается ошибкой. При уничтожении `input` поток закрывает файл.

Применяйте правило нуля. Если поля уже управляют ресурсами, используйте сгенерированные операции копирования, перемещения и уничтожения.

Фрагмент определения типа. Подключите `<string>` и `<vector>`.

```cpp
struct ScoreBatch {
    std::string label;
    std::vector<int> scores;
};
```

Копия `ScoreBatch` получает собственные значения полей. При уничтожении объекта его поля освобождают ресурсы. Если нужно обернуть ресурс из C API, сначала проверьте, можно ли использовать `std::unique_ptr` с пользовательской функцией освобождения.

<a id="lifetimes"></a>

## Время жизни и перемещение

| Намерение | Средство | Условие |
| --- | --- | --- |
| Хранить данные в объекте | Поля по значению, `std::string`, `std::vector` | Объект управляет временем жизни своих данных. |
| Передать исключительное владение | `std::unique_ptr<T>`, `std::move` | Новый владелец освобождает ресурс. |
| Разделить владение | `std::shared_ptr<T>` | Ресурс нужен нескольким независимым владельцам. Для наблюдения без продления жизни подходит `std::weak_ptr<T>`. |
| Временно использовать чужие данные | `T&`, указатель, `std::span`, `std::string_view` | Владелец должен сохранить память доступной. |

Фрагмент для тела функции. Подключите `<memory>` и `<utility>`.

```cpp
auto owner = std::make_unique<int>(60);
auto new_owner = std::move(owner);
```

`*new_owner` равно 60, а `owner` после этого перемещения пуст. `std::move` позволяет выбрать операцию перемещения. Владение передаёт конструктор `unique_ptr`. Для других типов проверяйте гарантии состояния после перемещения перед чтением объекта.

Ссылка, указатель и представление могут пережить данные, на которые ссылаются. Возвращайте локальные данные по значению. Если `push_back` перераспределил память вектора, получите указатели, ссылки и итераторы заново. Если представление ссылается на память вектора, создайте представление заново. [Правила `vector` в проекте стандарта](https://github.com/cplusplus/draft/blob/n4861/source/containers.tex) · [C++ Core Guidelines](https://isocpp.github.io/CppCoreGuidelines/CppCoreGuidelines).

## Паттерны и границы компонентов

| Задача | Паттерн | Приём в C++ |
| --- | --- | --- |
| Заменить правило отбора | Стратегия | Передайте лямбду или функциональный объект в алгоритм. |
| Преобразовать внешний ввод для функции | Адаптер | Преобразуйте аргументы и ошибки на границе консольной программы. |
| Выбрать реализацию по конфигурации | Фабрика | Возвращайте `std::unique_ptr<Interface>`, если вызывающий код получает владение. Объявите виртуальный деструктор в интерфейсе. |
| Уведомить несколько компонентов о событии | Наблюдатель | Регистрируйте функции обратного вызова. Свяжите снятие подписки со временем жизни объекта подписки. |
| Управлять временем жизни ресурса | RAII | Храните ресурс в объекте со стандартной операцией освобождения. |

Фрагмент для тела функции. Подключите `<algorithm>` и `<array>`. Алгоритм остаётся тем же при замене предиката.

```cpp
const std::array scores{55, 60, 100};
const auto passing = std::ranges::count_if(scores, [minimum = 60](int score) {
    return score >= minimum;
});
const auto perfect = std::ranges::count_if(scores, [](int score) {
    return score == 100;
});
```

`passing` равно 2, а `perfect` равно 1. Лямбда передаёт отдельное правило подсчёта. Если вызывающая сторона должна хранить стратегии разных типов в одной переменной, рассмотрите `std::function` с общей сигнатурой.

В учебном проекте консольный адаптер преобразует строки в `int` и передаёт данные функции подсчёта через `std::span`. Адаптер превращает `std::invalid_argument` в сообщение и код завершения 2. Смена способа ввода сохраняет контракт подсчёта, если адаптер передаёт тот же набор аргументов. [Консольный адаптер](../../../examples/cpp/score-count.cpp) · [Контракт подсчёта](../../../examples/cpp/score-summary.hpp) · [Запуск тестов](tooling-and-testing.md#tests).

Проверяйте границы данных при входе в компонент. Для диагностики сначала включите предупреждения компилятора и запустите тесты. Если важна производительность, измеряйте время и потребление ресурсов на данных, близких к рабочим. [Диагностика учебного проекта](tooling-and-testing.md#diagnostics) · [Google Benchmark](https://github.com/google/benchmark).
