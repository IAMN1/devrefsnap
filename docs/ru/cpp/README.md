## Первый запуск

Используйте Clang и стандартную библиотеку с поддержкой C++20. Выполните команды в Bash или Zsh из корня репозитория. [Полная программа `basics.cpp`](../../../examples/cpp/basics.cpp) использует данные из исходника.

```bash
build_dir=$(mktemp -d) &&
  clang++ -std=c++20 -Wall -Wextra -pedantic examples/cpp/basics.cpp -o "$build_dir/basics" &&
  "$build_dir/basics"
```

Флаг `-std=c++20` выбирает стандарт языка. Драйвер `clang++` компилирует исходник и подключает стандартную библиотеку при компоновке. Выполнение начинается в `main`. Проверьте вывод команды.

```text
Count: 2
```

## Типы и управление потоком

В примере `int` хранит балл, а `std::size_t` хранит число совпадений. Цикл `for (int score : scores)` копирует очередной балл. Условие `score >= minimum` включает значение на границе. См. [типы и циклы](syntax.md#values).

## Функции

Параметр `const std::vector<int>& scores` даёт функции доступ на чтение без копирования вектора. Объявите функцию до вызова. См. [выбор типа параметра](syntax.md#parameters).

## Коллекции

Фрагмент `main` из [первого примера](../../../examples/cpp/basics.cpp). Подключите `<vector>`.

```cpp
std::vector<int> scores{2, 5};
scores.push_back(3);
```

`scores.size()` возвращает 3. Вектор владеет памятью для элементов. См. [выбор контейнера](syntax.md#standard-library).

## Типичные ошибки

| Симптом | Что проверить |
| --- | --- |
| Компоновщик сообщает об отсутствующих символах стандартной библиотеки | Собирайте программу через `clang++`. В проекте CMake проверьте [связи целей](tooling-and-testing.md#cmake-targets). |
| Индекс может выйти за границы | Используйте `scores.at(i)` для проверки. Метод выбрасывает `std::out_of_range` при неверном индексе. |
| Ссылка на элемент пережила перераспределение памяти вектора | Получите ссылку заново после `push_back`, если добавление могло увеличить ёмкость. См. [время жизни](practice.md#lifetimes). |
