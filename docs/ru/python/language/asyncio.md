# Первые шаги с `asyncio`

[English](../../../en/python/language/asyncio.md)

Используйте `asyncio`, когда несколько операций могут ждать ввода-вывода одновременно.
На странице вы запустите корутину и сравните два способа дождаться независимых операций.

| Задача | Приём | Пример |
| --- | --- | --- |
| Запустить асинхронную функцию | `async def`, `await`, `asyncio.run()` | [Первая корутина](#запустить-корутину) |
| Получить результаты по очереди | Два вызова с `await` | [Последовательное ожидание](#дождаться-операций-по-очереди) |
| Совместить ожидания | `asyncio.TaskGroup` | [Конкурентное ожидание](#дождаться-операций-конкурентно) |

Подготовьте Python 3.11 или новее для `TaskGroup`. Примеры используют только стандартную библиотеку.
Достаточно знать, как объявить и вызвать функцию.

## Запустить корутину

Вызов функции `async def` создаёт объект корутины без выполнения её тела. Чтобы выполнить корутину, используйте `await` или запланируйте её как задачу.
В обычном скрипте запустите корутину верхнего уровня через `asyncio.run()`.

Сохраните полный пример в `hello_async.py`.

```python
import asyncio


async def answer() -> int:
    print("running")
    return 42


async def main() -> None:
    coroutine = answer()
    print("created")
    print(await coroutine)


if __name__ == "__main__":
    asyncio.run(main())
```

Выполните `python3 hello_async.py` из каталога файла.
Сначала программа выведет `created`, затем `running` и `42`.
`asyncio.run()` создаёт цикл событий и закрывает его в конце. Если в том же потоке уже работает цикл событий, используйте `await` внутри асинхронного кода.

## Дождаться операций по очереди

Две независимые операции в примере используют одну функцию `fetch()`. Функция ждёт 0,2 секунды через `await asyncio.sleep(0.2)` и возвращает полученное имя.
Так пример имитирует ожидание ввода-вывода без сети.

В этом фрагменте `main()` ждёт каждую корутину отдельно.

```python
first = await fetch("A")
second = await fetch("B")
```

`fetch("B")` начнётся после завершения `fetch("A")`. Программа получит `A` и `B` примерно за 0,4 секунды.

## Дождаться операций конкурентно

Добавьте обе корутины в одну группу задач. Пока одна задача ждёт, цикл событий может выполнять другую готовую задачу.

Этот фрагмент `main()` использует импорт `asyncio` и ту же функцию `fetch()`.

```python
async with asyncio.TaskGroup() as group:
    first_task = group.create_task(fetch("A"))
    second_task = group.create_task(fetch("B"))

print(first_task.result(), second_task.result())
```

При успешном выходе из `async with` обе задачи завершены. Программа получит те же значения примерно за 0,2 секунды, потому что ожидания перекрываются.
Если задача завершится обычным исключением, группа запросит отмену оставшихся задач и дождётся их завершения.
Используйте последовательное ожидание, если второй операции нужен результат первой.

## Сохранить отзывчивость цикла событий

`time.sleep()` и синхронный HTTP-клиент блокируют поток цикла событий при прямом вызове. Длительное вычисление в том же потоке тоже задерживает другие задачи.
Для асинхронного ожидания используйте `asyncio.sleep()` или асинхронный API ввода-вывода. Если доступна только блокирующая функция ввода-вывода, её можно запустить в отдельном потоке через `await asyncio.to_thread(...)`.
