# Первая программа на Python

[English](../../../en/python/language/first-program.md) · [К разделу Python](../README.md)

Посчитайте стоимость трёх билетов по 50 рублей. Если на компьютере ещё нет Python 3, [установите Python](https://www.python.org/downloads/).

## Запустите программу

Сохраните эти три строки в файле `tickets.py` в любой удобной папке. Можно также скачать [готовый файл](../../../../examples/python/language/tickets.py).

```python
ticket_price = 50
tickets = 3
print(ticket_price * tickets)
```

Откройте терминал в папке с файлом. Выполните команду.

```bash
python3 tickets.py
```

В Windows с установленным средством запуска Python используйте `py tickets.py`.

Программа выведет `150`. Первая строка задаёт цену билета, вторая — количество билетов. Знак `*` умножает эти значения. Функция `print()` выводит результат.

## Измените одно число

Замените `tickets = 3` на `tickets = 4`. Какое число теперь выведет программа? Сохраните файл. Повторите ту же команду.
