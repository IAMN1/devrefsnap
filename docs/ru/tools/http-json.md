# Прочитать HTTP-ответ с JSON

[English](../../en/tools/http-json.md) · [Инструменты разработки](README.md)

Отправьте GET-запрос из терминала и проверьте ответ сервера. Учебный сервер работает на вашем компьютере и возвращает JSON из файла.

| Задача | Приём | Пример |
| --- | --- | --- |
| Посмотреть статус, заголовки и тело ответа | `curl -i` | [HTTP-ответ](#посмотреть-http-ответ) |
| Получить имя из тела ответа | `jq -r '.name'` | [Поле JSON](#извлечь-поле-json) |

## Запустить учебный сервер

Для запуска нужны `python3`, `curl` и `jq`. Команды рассчитаны на Bash и Zsh. Сервер использует стандартную библиотеку Python. Пример проверен с Python 3.14.

В первом терминале выполните команду из корня репозитория. Сервер читает [полный учебный файл `item.json`](../../../examples/tools/http-json/item.json) и слушает только локальный адрес `127.0.0.1`.

```bash
python3 -m http.server 8765 --bind 127.0.0.1 --directory examples/tools/http-json
```

Оставьте сервер запущенным. Если порт `8765` занят, выберите свободный порт и замените `8765` в командах запуска и запросов.

## Посмотреть HTTP-ответ

Во втором терминале выполните GET-запрос. Параметр `-i` добавляет к выводу статус и заголовки ответа. Параметр `--noproxy 127.0.0.1` направляет запрос к локальному серверу напрямую.

```bash
curl --noproxy 127.0.0.1 -i http://127.0.0.1:8765/item.json
```

Сокращённый вывод выглядит так.

```http
HTTP/1.0 200 OK
Content-type: application/json

{"id": 1, "name": "Book"}
```

В первой строке код `200` означает, что запрос выполнен успешно. Заголовок `Content-Type` указывает формат тела. Тело ответа начинается после пустой строки.

Если сервер вернул `404`, проверьте путь `/item.json` в URL и каталог, переданный через `--directory`.

## Извлечь поле JSON

Выполните запрос без `-i`, чтобы передать в `jq` только тело ответа. Параметры `-sS` скрывают индикатор загрузки и сохраняют сообщения об ошибках `curl`.

```bash
curl --noproxy 127.0.0.1 -sS http://127.0.0.1:8765/item.json | jq -r '.name'
```

Фильтр `.name` извлекает значение поля `name`. Параметр `-r` выводит строку без кавычек JSON.

```text
Book
```

Чтобы остановить сервер, нажмите `Ctrl+C` в первом терминале.
