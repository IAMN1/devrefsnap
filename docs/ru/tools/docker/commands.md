# Шпаргалка по командам Docker Compose

[English](../../../en/tools/docker/commands.md)

Выполняйте команды в каталоге с `compose.yaml`. Имена `gateway` и `catalog` взяты из [примера с тремя сервисами](lab.md). Команда `docker compose config --services` покажет имена в вашем проекте.

| Нужно | Команда | Что произойдёт |
| --- | --- | --- |
| Проверить файл | `docker compose config -q` | Вернёт код 0 при корректной конфигурации. Без `-q` покажет итоговые настройки. |
| Собрать образ | `docker compose build catalog` | Соберёт образ. Работающий контейнер продолжит использовать прежний. |
| Запустить проект в фоне | `docker compose up -d` | Создаст недостающие ресурсы и запустит сервисы. Без `-d` журнал останется в терминале, а `Ctrl+C` остановит контейнеры. |
| Собрать и запустить | `docker compose up -d --build` | Соберёт образы и при необходимости пересоздаст контейнеры. |
| Найти остановленный контейнер | `docker compose ps -a` | Покажет состояние каждого контейнера, включая завершившиеся. |
| Узнать адрес с компьютера | `docker compose port gateway 80` | В примере выведет `127.0.0.1:18083` при стандартном порте. |
| Следить за журналом процесса | `docker compose logs --tail 20 -f catalog` | Покажет последние 20 строк и новые записи. `Ctrl+C` закроет просмотр. |
| Остановить и снова запустить | `docker compose stop catalog`, затем `docker compose start catalog` | Сохранит контейнер и его настройки. |
| Перезапустить процесс | `docker compose restart catalog` | Запустит тот же контейнер с прежними настройками. |
| Завершить работу | `docker compose down` | Удалит контейнеры и сети проекта. Именованные тома останутся. |

Для другого файла укажите `-f` перед подкомандой. Пример из корня репозитория — `docker compose -f examples/tools/compose-site/compose.yaml config --services`. Флаг `-p` задаёт имя проекта. Используйте одно имя для запуска и очистки. Параллельным экземплярам понадобятся разные порты компьютера. [Справочник CLI](https://docs.docker.com/reference/cli/docker/compose/).

## Выбрать exec или run

| Задача | Команда | Куда она попадёт |
| --- | --- | --- |
| Прочитать файл в работающем сервисе | `docker compose exec catalog cat message.txt` | В существующий контейнер. Для скрипта добавьте `-T`, чтобы отключить выделение терминала. |
| Выполнить отдельную команду | `docker compose run --rm catalog python --version` | В новый контейнер с настройками сервиса. После выхода он удалится. Порты сервиса по умолчанию не публикуются. |

## Применить изменение

| Что изменилось | Что применит изменение |
| --- | --- |
| Dockerfile или файл, который входит в образ через `COPY` | `docker compose up -d --build`. Если путь закрыт томом, контейнер увидит содержимое тома. [Почему так происходит](guide.md#что-остаётся-после-пересоздания). |
| `ports` или `environment` в Compose | `docker compose up -d` пересоздаст затронутый контейнер. |
| Содержимое файла с компьютера, подключённого через bind mount | Приложение увидит обновлённые данные при следующем чтении. Если оно читает настройки только на старте, перезапустите его. |
| Готовый образ в реестре под тем же тегом | `docker compose pull gateway`, затем `docker compose up -d`. При обновлении БД проверьте совместимость с данными тома. |

[Упражнение с пересборкой одного сервиса](first-run.md#применить-изменение) · [Поведение up](https://docs.docker.com/reference/cli/docker/compose/up/).

## Найти причину сбоя

| Симптом | Что проверить |
| --- | --- |
| Нет соединения с Docker Engine | В `docker version` найдите секцию `Server`. Проверьте Docker Desktop или Engine и выбранное окружение через `docker context show`. |
| Не найден сервис | `docker compose config --services` покажет допустимые имена для текущего файла. |
| Порт занят | Задайте свободный порт через `SITE_PORT` и примените настройки командой `up -d`. Адрес покажет `docker compose port gateway 80`. |
| Шлюз вернул 502 или контейнер завершился | Откройте `docker compose ps -a` и `docker compose logs --tail 30 gateway catalog help`. [Восстановление маршрута](lab.md#запуск). |
| Сервер вернул 404 для каталога | `docker compose exec catalog ls` покажет доступные файлы. В примере полный путь запроса — `/catalog/message.txt`. |
| Приложение не находит PostgreSQL | Проверьте имя сервиса, общий сегмент сети и готовность БД. [Подключение базы данных](compose-file.md#подключить-базу-данных). |
