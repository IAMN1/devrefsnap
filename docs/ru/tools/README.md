
# Инструменты разработки

[English](../../en/tools/README.md)

Найдите пример по задаче или синониму в указателе [HTTP и JSON](../tasks/README.md#http-api-и-веб-приложения), [Docker Compose и CI](../tasks/README.md#docker-compose-и-ci) или [Git и GitHub](../tasks/README.md#git-и-github).

Раздел содержит общие инструменты для проектов на разных языках.
Материалы охватывают проверку HTTP, запуск приложений с зависимостями, CI, управление версиями и совместную работу.
Инструменты экосистемы Python находятся в [разделе Python](../python/README.md).
К ним относятся [uv](../python/tooling/uv/README.md) и [pytest](../python/testing/pytest/README.md).


## Материалы

| Тема | Содержание |
| --- | --- |
| [HTTP и JSON](http-json.md) | Запрос через curl, статус, заголовки, тело и выбор поля через jq |
| [Docker Compose и GitHub Actions](compose-and-github-actions.md) | Приложение с PostgreSQL, тесты и разбор падения по журналу |
| [Проверка контракта HTTP API](api-contract-lab.md) | FastAPI, PostgreSQL и TypeScript с одной проверкой в Compose и CI |
| [Git](git/README.md) | Карточки рабочих задач, отмена, конфликты и проверка удалённых веток |
| [GitHub Pull Requests](github-pull-requests/README.md) | Создание PR, ревью, проверки и способы слияния |

Полные Git-примеры используют отдельные учебные репозитории.
Последствия изменения истории и удаления объясняются рядом с командами.

Основные команды и история репозитория относятся к [Git](git/README.md).
Обсуждение и интеграция изменений на GitHub относятся к [Pull Requests](github-pull-requests/README.md).
