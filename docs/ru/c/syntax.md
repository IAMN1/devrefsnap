## Типы и управление потоком

| Задача | Тип или конструкция | Условие |
| --- | --- | --- |
| Хранить целое число или логический флаг | `int`, `bool` из `<stdbool.h>` | Для заданного диапазона сверяйте пределы из `<limits.h>`. |
| Хранить размер или индекс | `size_t` из `<stddef.h>` | Тип беззнаковый. Для вывода через `printf` используйте `%zu`. |
| Хранить число точной ширины | `int32_t`, `uint32_t` из `<stdint.h>` | Типы точной ширины доступны, если реализация поддерживает такие представления. |
| Вычислить дробное значение | `double ratio = 3.0 / 2.0;` | Деление `3 / 2` даёт целое `1`. |
| Выбрать действие по условию или коду | `if` / `else`, `switch` | В `switch` используйте `break`, чтобы завершить ветку `case`. |
| Повторить действие | `for`, `while`, `do` / `while` | `do` / `while` проверяет условие после выполнения тела. |

Фрагмент из [полной программы подсчёта](../../../examples/c/basics.c). Функция объявляет результат и проверяет каждый элемент массива. Вызывающая сторона передаёт число доступных элементов.

```c
#include <stddef.h>

static size_t count_at_least(const int *scores, size_t length, int minimum)
{
    size_t count = 0;
    for (size_t i = 0; i < length; ++i) {
        if (scores[i] >= minimum) {
            ++count;
        }
    }
    return count;
}
```

В выражении `x == y` оператор сравнивает значения. Оператор `=` присваивает значение. Операторы `&&` и `||` могут пропустить вычисление правого операнда. Переполнение знакового целого ведёт к неопределённому поведению. Арифметика беззнакового типа выполняется по модулю. Проверяйте диапазон до вычисления размера буфера.

## Массивы, строки и указатели

Фрагмент для вызова `count_at_least` из предыдущей карточки. Вызов возвращает `2`.

```c
const int scores[] = {2, 5, 3};
const size_t length = sizeof scores / sizeof scores[0];
const size_t count = count_at_least(scores, length, 3);
```

В вызове массив преобразуется в указатель на первый элемент. Передавайте число элементов отдельным аргументом. В параметре функции запись `int values[]` также задаёт тип указателя.

| Запись | Действие или свойство |
| --- | --- |
| `&value` | Получить адрес объекта. |
| `*pointer` | Обратиться к объекту по действительному указателю. |
| `const int *pointer` | Читать `int` через указатель. Сам указатель можно переназначить. |
| `int *const pointer = &value;` | Зафиксировать адрес в указателе. Через указатель можно изменить `int`. |
| `char label[] = "ok";` | Создать изменяемый массив из трёх элементов, включая `'\0'`. |
| `const char *label = "ok";` | Читать строковый литерал. Изменение литерала ведёт к неопределённому поведению. |

Строковая функция вроде `strlen` требует доступный завершающий `'\0'`. Длина `strlen("ok")` равна 2. Для произвольного буфера храните длину в байтах отдельно. Для текста UTF-8 число байтов может отличаться от числа символов.

## Функции, структуры и обратные вызовы

Функция получает копии аргументов. Передайте адрес, если функция должна изменить объект вызывающей стороны. Прототип `int run(void);` объявляет функцию без параметров. Функция с `static` на уровне файла доступна только в своей [единице трансляции](tooling-and-testing.md#собрать-и-скомпоновать-файлы).

Фрагмент обхода показаний с обратным вызовом. Объявления используют `size_t` из `<stddef.h>`.

```c
#include <stddef.h>

struct reading {
    unsigned int sensor;
    double value;
};

typedef void (*reading_fn)(const struct reading *reading, void *context);

static void visit_readings(const struct reading *readings, size_t length,
                           reading_fn visit, void *context)
{
    for (size_t i = 0; i < length; ++i) {
        visit(&readings[i], context);
    }
}
```

Создайте значение через `struct reading item = {.sensor = 2, .value = 3.5};`. Читайте поле через `item.value` или `ptr->value`. Передайте действительный указатель `visit` и массив с `length` элементами. Каждый вызов получает адрес показания и контекст вызывающей стороны. Контекст и массив должны оставаться действительными до завершения обхода. Если обратный вызов сохраняет адрес, согласуйте срок жизни отдельно.

Используйте `enum` для именованных состояний. [Парсер порта](../../../examples/c/port-parser/port.h) возвращает `enum port_status`. Храните двоичный формат отдельно от представления `struct` в памяти. Компилятор может добавлять промежутки между полями, а порядок байтов зависит от платформы.

## Стандартная библиотека

Подключите заголовок до использования API. Проверяйте условие успеха каждой операции по её контракту.

| Задача | Заголовок и API | Существенное условие |
| --- | --- | --- |
| Вывести результат, прочитать файл | `<stdio.h>` · `printf`, `fopen`, `fgets`, `fclose` | Проверьте формат и результаты операций. Если `fgets` вернул `NULL`, различите конец файла и ошибку через `feof` и `ferror`. |
| Преобразовать текст в целое | `<stdlib.h>` · `strtol` | Обнулите `errno` из `<errno.h>` перед вызовом. Проверьте отсутствие цифр, остаток строки, `ERANGE` и прикладной диапазон. В [парсере порта](../../../examples/c/port-parser/port.c) проверка строки идёт до преобразования. |
| Выделить и освободить память | `<stdlib.h>` · `malloc`, `realloc`, `free` | Проверьте размер и указатель. Назначьте владельца, который вызовет `free`. |
| Сравнить строки или скопировать байты | `<string.h>` · `strcmp`, `memcpy`, `memmove` | `strcmp` возвращает 0 для равных строк. Для перекрывающихся областей используйте `memmove`. |
| Проверить пробельный символ или перевести букву в нижний регистр | `<ctype.h>` · `isspace((unsigned char)ch)`, `tolower((unsigned char)ch)` | Эти вызовы используют `char ch`. Для пробельного символа `isspace` возвращает ненулевое значение. При чтении через `getchar()` храните результат в `int`, чтобы различать байт и `EOF`. |
| Проверить внутренний инвариант | `<assert.h>` · `assert` | При `NDEBUG` проверка исчезает. Проверяйте пользовательский ввод обычным условием. |
| Выполнить вычисление | `<math.h>` · `sqrt`, `isfinite` | Проверьте область определения. Некоторые Unix-инструменты требуют добавить `-lm` при компоновке. |
