## Первый запуск

Подготовьте Clang с поддержкой C17 и стандартную библиотеку C. Команды рассчитаны на Bash или Zsh.

Из корня репозитория соберите и запустите [полную программу `basics.c`](../../../examples/c/basics.c). Программа использует массив из исходника.

```bash
build_dir=$(mktemp -d) &&
  clang -std=c17 -Wall -Wextra -pedantic examples/c/basics.c -o "$build_dir/basics" &&
  "$build_dir/basics"
```

Флаг `-std=c17` выбирает стандарт языка. Флаги `-Wall`, `-Wextra` и `-pedantic` включают дополнительные предупреждения. Выполнение начинается в `main`. Значение `return 0` означает успешное завершение программы.

```text
Count: 2
```

## Типы и управление потоком

Программа использует `int` для значений массива и `size_t` для длины и индекса. При нулевой длине функция пропускает цикл и возвращает 0. Условие `if` включает в подсчёт элементы, равные порогу. См. [типы и управление потоком](syntax.md#типы-и-управление-потоком).

## Функции

Объявите функцию до вызова. Функция `count_at_least` получает копии указателя, длины и порога. См. [функции, структуры и обратные вызовы](syntax.md#функции-структуры-и-обратные-вызовы).

## Массивы и память

В месте объявления массива вычислите длину через `sizeof scores / sizeof scores[0]`. При вызове передайте указатель на первый элемент и длину. См. [массивы, строки и указатели](syntax.md#массивы-строки-и-указатели).

## Типичные ошибки

| Ошибка | Что сделать |
| --- | --- |
| Обращение к `scores[length]` | Проверяйте `i < length` перед чтением. Выход за границу ведёт к неопределённому поведению. |
| Вычисление длины через `sizeof scores` внутри функции | Используйте параметр `length`. В функции `sizeof scores` даёт размер указателя в байтах. |
| Возврат указателя на локальный массив | Передайте функции буфер вызывающего кода и его ёмкость. Функция запишет результат в буфер, который остаётся доступным после возврата. См. [владение ресурсами](practice.md#patterns). |
| Вывод `size_t` через `%d` | Используйте `%zu` в `printf`. |
