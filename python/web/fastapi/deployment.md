# Запустить API и собрать контейнер

Откройте страницу, чтобы запустить готовое учебное API, выбрать процессы или собрать локальный контейнер.
Приложение `minimal.py` должно быть импортируемым из папки запуска.

| Задача | Приём | Пример / подробности |
| --- | --- | --- |
| Перезапускать сервер при изменении кода | Uvicorn `--reload` | [Разработка](#разработка-и-несколько-процессов) |
| Запустить несколько процессов | `--workers`; память раздельная | [Workers](#разработка-и-несколько-процессов) |
| Использовать существующий Gunicorn | Отдельный `uvicorn-worker` | [Вариант запуска](#gunicorn-как-отдельный-вариант) |
| Собрать контейнер или сохранить схему | Dockerfile либо `app.openapi()` | [Контейнер](#контейнер-для-минимального-приложения) · [OpenAPI](#сохранить-openapi) |

[Краткий справочник](README.md) · [Первое приложение](README.md#первый-запуск)

| Параметр | Значение |
| --- | --- |
| Уровень | Средний: запуск; продвинутый: процессы и контейнер |
| Предпосылки | Виртуальное окружение, терминал; для контейнера — Docker |

Выполняйте все команды в отдельной учебной папке с `minimal.py` из README темы.
Пример демонстрирует запуск.
Пример не публикует сервис.

## Разработка и несколько процессов

Используйте Python 3.14.7, FastAPI 0.162.0 и Uvicorn 0.54.0.
Выполните `python -m pip install 'fastapi==0.162.0' 'uvicorn[standard]==0.54.0'`.

```bash
uvicorn minimal:app --reload --host 127.0.0.1 --port 8000
```

В другом терминале запустите `curl http://127.0.0.1:8000/`.
Ожидается `200` и `{"message":"Привет"}`.
`Ctrl+C` останавливает сервер.
`--reload` перезапускает сервер при изменении файлов.
Этот режим нужен в разработке.

Запуск нескольких процессов без reload:

```bash
uvicorn minimal:app --host 127.0.0.1 --port 8000 --workers 2
```

Два workers — выбранное число для примера.
Это число не является рекомендацией по размеру сервера.
Каждый процесс имеет собственную память.
Каждый процесс выполняет собственный lifespan.
Поэтому словарь товаров из `main.py` нельзя использовать как общую БД.
Для внешнего доступа за прокси или в контейнере укажите `--host 0.0.0.0`.
Настройте HTTPS в соответствии с окружением.
Настройте доверие proxy headers в соответствии с окружением.
`--reload` и `--workers` не совмещаются.

## Gunicorn как отдельный вариант

Если развёртывание на Linux/Unix уже использует Gunicorn, установите `gunicorn` и отдельный `uvicorn-worker` в окружение приложения:

```bash
python -m pip install gunicorn uvicorn-worker
gunicorn minimal:app -w 2 -k uvicorn_worker.UvicornWorker -b 127.0.0.1:8000
```

Старый путь `uvicorn.workers.UvicornWorker` устарел.
Для простого запуска можно использовать встроенные workers Uvicorn.
Выбирать Gunicorn только ради этого примера не требуется.
[Источник: Uvicorn deployment](https://uvicorn.dev/deployment/).

## Контейнер для минимального приложения

Создайте в учебной папке `requirements.txt`.
Файл содержит минимальные зависимости для `minimal.py`.
Этот набор не покрывает все рецепты:

```text
fastapi==0.162.0
uvicorn==0.54.0
```

Dockerfile:

```dockerfile
FROM python:3.14-slim
WORKDIR /app
COPY requirements.txt .
RUN python -m pip install --no-cache-dir -r requirements.txt
COPY minimal.py .
USER 10001:10001
EXPOSE 8000
CMD ["uvicorn", "minimal:app", "--host", "0.0.0.0", "--port", "8000"]
```

```bash
docker build -t fastapi-training .
docker run --rm -p 127.0.0.1:8000:8000 fastapi-training
```

Команды создают локальный образ.
Затем команды запускают контейнер с портом, доступным только на localhost.
Проверьте ответ через `curl http://127.0.0.1:8000/`.
Остановите контейнер через `Ctrl+C`.
`--rm` удалит завершённый контейнер.
Образ останется.
Публикации в registry здесь нет.

Обновляйте тег базового образа и версии пакетов осознанно.
Этот Dockerfile не подтверждает работу на всех платформах/архитектурах.
Для воспроизводимого окружения проекта зафиксируйте транзитивные зависимости lock-файлом.
При необходимости зафиксируйте digest образа.
В оркестраторе часто запускают один процесс на контейнер.
Затем масштабируют контейнеры.
Выбор зависит от инфраструктуры.

## Сохранить OpenAPI

Команда импортирует учебное приложение.
Затем команда записывает или перезаписывает `openapi.json` в текущей папке:

```bash
python -c 'import json; from minimal import app; print(json.dumps(app.openapi(), ensure_ascii=False, indent=2))' > openapi.json
```

Либо получите `/openapi.json` у работающего сервера.
Генерация схемы не отправляет запросы к маршрутам.
Генерация схемы не заменяет [поведенческие тесты](testing.md).
