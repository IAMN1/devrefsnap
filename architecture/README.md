# Архитектура и проектирование

Общие принципы и способы организации кода и систем. Здесь объясняются задачи, границы применения
и компромиссы; применение к Python-проекту разобрано в [отдельном руководстве](../python/architecture/project-design/README.md).

| Тема | Что искать |
| --- | --- |
| [Архитектурные принципы](principles.md) | Границы, контракты, связность, зависимости, инварианты и компромиссы |
| [SOLID](solid.md) | Пять принципов, их смысл и проверяемые примеры |
| [Паттерны](patterns/README.md) | Выбор между паттернами кода, архитектуры и распределённого взаимодействия |

Начинай с конкретной проблемы и ограничения. Принцип помогает оценить решение,
паттерн предлагает известную форму решения, а тест проверяет конкретное поведение реализации.
Успешный пример сам по себе не доказывает пригодность архитектуры для любой нагрузки и команды.

В справочниках выделены три уровня; подробные примеры и схемы имеют явные предпосылки.
Версии среды и границы выполнения указаны рядом с кодом.
