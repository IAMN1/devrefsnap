# Шаблоны материалов

Выберите шаблон по задаче страницы.
Русскоязычные материалы используют [русский профиль STE 80%](../AGENTS.md#стиль-русского-текста-ste-80).

## Выбор формата

| Читателю нужно | Формат | Шаблон |
| --- | --- | --- |
| Вспомнить синтаксис команды или выбрать API | Найти действие, скопировать короткий фрагмент, увидеть результат | [Шпаргалка](cheat-sheet.md) |
| Понять, почему решение работает | Проследить один пример, изменить условие и объяснить результат | [Методичка](guide.md) |
| Посмотреть все файлы или повторить пример | Открыть исходники, подготовить данные, запустить и проверить результат | [Полный пример или практикум](standalone-example.md) |
| Выполнить операцию в заданном порядке | Проверить исходное состояние, выполнить шаги, распознать успех или исправить отказ | [Процедура](procedure.md) |

Например, в теме Docker можно [найти инструкцию](../docs/ru/tools/docker/dockerfile.md), [разобрать путь запроса](../docs/ru/tools/docker/guide.md) или [запустить сайт из трёх сервисов](../docs/ru/tools/docker/lab.md). Для короткой темы достаточно одной страницы. Выносите материал по ссылке, когда подготовка или объяснение скрывают нужный ответ.

## Подробная страница

Назовите самостоятельную задачу и добавьте ссылку обратно к справочнику.
Укажите только подготовку, необходимую этой задаче.
Для нескольких независимых программ разместите выбор перед установкой зависимостей.

Базовый, средний и продвинутый уровни помогают выбрать материал, если различие существенно.
Создавать отдельные разделы уровней для каждой страницы не требуется.
Оглавление нужно для длинной страницы, а не для заполнения шаблона.

Если тесты уже проверяют случаи, приведите ожидаемый результат запуска и поясните существенные проверки.
Если таблица содержит ожидаемые значения, используйте её как единственный перечень результатов.
Чек-лист нужен для самостоятельных действий читателя в процедуре.

Условия потери данных, изменения истории, миграции и восстановления находятся рядом с соответствующими командами.
Требования запуска находятся на учебной странице.
Значимые результаты фактических прогонов сохраняются в [сопровождении](../maintenance/README.md).

## Как выбрать представление

Поместите команду, путь или короткий код рядом с вопросом, на который они отвечают. Для выбора между вариантами укажите в таблице условие, которое меняет решение. Используйте дерево, если взаимное расположение файлов объясняет путь. Перед схемой сформулируйте вопрос, а на стрелках подпишите действия или данные.

Проверьте страницу с двух точек входа. Из каталога читатель должен выбрать задачу по названию ссылки. По прямой ссылке на раздел он должен понять исходные условия и ожидаемый результат. [Разбор реальных справочников и уроков](../maintenance/reports/reference-formats.md)
