# Шаблоны материалов

[Задачи оформления в общем указателе](../tasks/README.md#оформление-материалов).

Раздел содержит общие образцы оформления шпаргалок и практических страниц.
Образцы задают структуру.
Проверяйте техническое содержание каждой темы отдельно.

- [Шаблон шпаргалки и подробной страницы](cheat-sheet.md)
- [Сравнение текущей подачи и двух русских адаптаций STE](ste-comparison/README.md) — отдельный эксперимент на одной странице.
- [Правила для агентов](../AGENTS.md)
- [Все материалы](../README.md)

При создании темы замените подсказки конкретным содержанием.
Уберите неиспользуемые части.
Размещайте рабочие примеры инструментов в соответствующем тематическом разделе.
Этот раздел содержит шаблоны.

## Выбор формата

Для новых и перерабатываемых страниц используйте [русский профиль «STE 80%»](../AGENTS.md#стиль-русского-текста-ste-80).
Сравнительные снимки сохраняют исходный стиль.

| Объём и назначение | Размещение |
| --- | --- |
| Компактный справочник | Один файл с тремя уровнями |
| Справочник и несколько длинных примеров | Каталог с `README.md` и `recipes.md` |
| Много независимых сценариев | `README.md` и страницы по задачам: `testing.md`, `deployment.md` и т. п. |

Для крупной темы оставьте `README.md` краткой точкой входа.
Группируйте подробности по задачам.
Указывайте уровень на каждой подробной странице.
Длина файла сама по себе не задаёт границу.
Для навигации используйте относительные ссылки.
Используйте обычные якоря заголовков GitHub.

## Подробная страница

Подробная страница имеет один H1 с названием задачи.
Добавьте ссылку на `README.md` темы.
Для самостоятельного сценария используйте порядок ниже.
В сборнике повторяйте порядок для каждого рецепта:

1. Укажите уровень.
2. Назовите задачу.
3. Укажите необходимые знания.
4. Перечислите зависимости.
5. Опишите подготовку окружения.
6. Укажите исходные данные.
7. Приведите полный пример или последовательность шагов.
8. Укажите язык и место выполнения.
9. Приведите команду проверки.
10. Укажите ожидаемый результат.
11. Укажите ограничения.
12. При необходимости опишите очистку учебных ресурсов.
13. Добавьте официальный источник.

В учебной странице укажите зависимости и существенные условия применения.
Храните отчёты о выполненных проверках и редакторской работе в [служебном каталоге](../maintenance/README.md).
Если страница охватывает несколько уровней, подпишите уровень каждого рецепта.
Для большого сборника составьте оглавление.
Самостоятельные задачи вынесите в файлы с предметными именами.
