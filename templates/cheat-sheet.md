## Карточка

Замените заголовок карточки действием читателя. Например, «Прочитать значение по ключу».
Назовите исходные данные. Если команда использует относительный путь, укажите каталог запуска.
Объясните выбранный приём, если его смысл не очевиден из кода.

```text
Здесь находится короткий пример.
Замените text языком примера при заполнении шаблона.
```

Укажите результат и существенное условие рядом с примером. Различайте возвращаемое значение, вывод в терминале и изменение состояния.
Для фрагмента назовите подготовленные объекты и нужные импорты.
Для самостоятельного запуска дайте ссылку на полный файл. Для разбора причин дайте ссылку на раздел методички с тем же примером.
