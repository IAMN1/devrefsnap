# Выполнить задачу

Назовите результат, который читатель получит после запуска. Сразу дайте ссылки на исходные файлы в `examples/`.
Дайте ссылку на короткую карточку справочника.

## Подготовка

Укажите необходимые знания, версию языка и минимальные зависимости этой программы. Укажите исходный каталог для команд.
Назовите файлы и исходные данные.
Если нужны служба или БД, опишите отдельное учебное окружение.

## Полный пример

```text
Здесь находятся импорты, подготовка данных и весь код программы.
Для нескольких файлов укажите путь перед каждым блоком.
Замените text нужным языком при заполнении шаблона.
```

Если показываете общий файл целиком, сверьте блок с этим файлом. Для длинного проекта достаточно ссылки на исходник и разбора существенного фрагмента. Подпишите такой блок как фрагмент.

## Запуск и результат

Приведите команду запуска и конкретный ожидаемый результат. Если идентификатор или счётчик меняется, укажите устойчивый признак успеха.
Если есть тесты, объясните проверяемое поведение и результат их запуска.
Используйте один перечень ожидаемых результатов.
Добавьте инструкции очистки, если программа создаёт внешние ресурсы.

Укажите существенные границы программы рядом с относящимся к ним кодом или результатом.

Для практикума добавьте упражнение на тех же файлах. Предложите изменить одно условие и укажите, по чему читатель проверит свой ответ.
