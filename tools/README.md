# Инструменты разработки

[Найти пример по задаче или синониму](../tasks/README.md#git-и-github) — Git, отмена изменений, ветки и Pull Requests.

Инструменты, общие для проектов на разных языках: управление версиями и совместная работа.
Инструменты экосистемы Python, включая [uv](../python/tooling/uv/README.md) и [pytest](../python/testing/pytest/README.md),
размещены в [разделе Python](../python/README.md).

## Материалы

| Тема | Содержание | Статус |
| --- | --- | --- |
| [Git](git/README.md) | Репозиторий, изменения, ветки и восстановление истории | Актуализировано |
| [GitHub Pull Requests](github-pull-requests/README.md) | Создание PR, ревью, проверки и способы слияния | Актуализировано |

Полные Git-примеры используют отдельные учебные репозитории. Действия в GitHub описаны
по документации; они не выполнялись в аккаунте. Последствия изменения истории и удаления
объясняются рядом с командами; границы проверки указаны в материалах.

Основные команды и история репозитория относятся к [Git](git/README.md),
а процесс обсуждения и интеграции изменений на GitHub — к [Pull Requests](github-pull-requests/README.md).
