# Инструменты разработки

Инструменты, общие для проектов на разных языках: управление версиями и совместная работа.
Инструменты экосистемы Python, включая [uv](../python/tooling/uv.md) и [pytest](../python/testing/pytest.md),
размещены в [разделе Python](../python/README.md).

## Материалы

| Тема | Содержание | Статус |
| --- | --- | --- |
| [Git](git.md) | Репозиторий, изменения, ветки и сообщения коммитов | Ожидает актуализации |
| [GitHub Pull Requests](github-pull-requests.md) | Создание PR, ревью и способы слияния | Ожидает актуализации |

Оба файла перенесены без изменения содержимого. Статус **«Ожидает актуализации»** означает,
что команды, рекомендации и навигация исходных материалов ещё требуют технической проверки.
Перенос не подтверждает безопасность команд изменения истории или удаления веток.

Основные команды и история репозитория относятся к [Git](git.md),
а процесс обсуждения и интеграции изменений на GitHub — к [Pull Requests](github-pull-requests.md).
При последующей актуализации повторяющиеся объяснения следует связать ссылками на основную тему.
